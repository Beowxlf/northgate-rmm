# Licensing Policy

## Project license

NorthGate RMM is licensed under the Apache License, Version 2.0
(`Apache-2.0`). The license covers repository-authored source code,
documentation, configuration, tests, and build material unless a file or
directory clearly states different terms.

The authoritative terms are in the repository-root `LICENSE` file. The
`NOTICE` file records project attribution and must accompany distributions that
include a notice file.

## Why Apache-2.0

Apache-2.0 permits use, modification, and redistribution while retaining
copyright and attribution notices. It also provides an explicit patent license
from contributors for patent claims necessarily infringed by their
contributions. This supports broad inspection, learning, deployment, and
collaboration without imposing network-copyleft requirements on RMM operators.

The license is not a security certification, support promise, trademark grant,
or warranty.

## Contributions

Unless a contributor explicitly states otherwise, an intentional contribution
submitted for inclusion is licensed under Apache-2.0 as described by section 5
of the license. A separate contributor-license agreement is not currently
required. That decision must be revisited before accepting contributions whose
ownership or employer authorization is unclear.

## Dependency rules

Every new direct and transitive dependency must have:

1. an identified SPDX license expression;
2. terms compatible with the intended distribution and deployment model;
3. required notices preserved in a third-party notice inventory;
4. security, maintenance, and provenance review; and
5. an approved exception before adding unclear, custom, source-available, or
   strong-copyleft terms.

Audit and development tools that are not distributed with the product are still
recorded and reviewed, but their licenses do not automatically become the
product license.

## Relicensing and published versions

Relicensing requires explicit owner authorization and all permissions needed
from affected copyright holders. Publishing a later version under different
terms does not withdraw rights already granted for an earlier Apache-2.0
version.

does not grant rights to project names, logos, or trademarks except as needed to
describe the work's origin.
